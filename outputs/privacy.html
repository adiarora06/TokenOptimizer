Privacy Policy

Token Optimizer Privacy Policy

This policy explains how Token Optimizer and the Token Optimizer for Gemini™ and ChatGPT Chrome extension handle prompt text and related data.

Effective date: August 10, 2026 Single purpose: prompt optimization No auto-send

Plain Summary

  • Prompt text is sent to Token Optimizer only when you click a Prepare action.
  • Prompt input and capture stay disabled until you agree to the visible data-use notice.
  • Extension preparation uses deterministic processing and does not call a provider AI model.
  • Raw and prepared prompt text is processed for the response and is not stored by Token Optimizer.
  • Nothing is sent to Token Optimizer when you capture text from or insert text into a supported assistant.
  • The extension does not auto-send Gemini™ or ChatGPT messages.
  • The extension does not store provider API keys, passwords, or account credentials.

Single Purpose

Token Optimizer for Gemini™ and ChatGPT has one purpose: helping users clean up, shorten, and clarify prompt text before inserting the reviewed result into a supported assistant.

Data We Process

  • Prompt text: text you paste into Token Optimizer or ask the extension to capture from Gemini™ or ChatGPT.
  • Optimized prompt output: the rewritten prompt returned by Token Optimizer so you can review, copy, or insert it.
  • Current-session display data: token counts, preparation strategy, and prepared output are held only in the open side panel. The extension stores no prompt text or usage history.
  • Operational request data: hosting infrastructure processes network address, time, route, status, and similar technical information to deliver, secure, rate-limit, and debug the service. Token Optimizer may create a short-lived keyed, pseudonymous rate-limit identifier from the network address.

How We Use Data

  • To convert rough or repetitive prompt text into cleaner prompt text.
  • To return the optimized prompt to the user for review.
  • To support the extension workflow: capture, prepare, insert, and review.
  • To maintain security, reliability, and debugging for the Token Optimizer service.

Data Sharing

The extension's preparation endpoint processes prompt text without sending it to a provider AI model. The identity of the supported assistant stays in the browser and is not sent to the preparation service. Vercel hosts the Token Optimizer service and necessarily processes prompt text in transit and in memory to return the prepared result. If shared abuse protection is enabled, Upstash processes pseudonymous, keyed rate-limit identifiers; prompt text is not stored in Upstash. Provider AI model processing occurs only when a user separately chooses to execute a task in the Token Optimizer workspace or sends the prepared prompt in Gemini™ or ChatGPT. We do not sell user data. We do not use or transfer user data for advertising, creditworthiness, lending, or unrelated purposes.

What We Do Not Collect

  • We do not intentionally collect names, postal addresses, payment information, health information, passwords, or authentication credentials. Network addresses are processed as operational request data as described above.
  • We do not collect browsing history.
  • We do not perform keystroke logging, mouse tracking, or general user activity monitoring.
  • We do not automatically read Gemini™ or ChatGPT conversations. Capture happens only when the user requests it after consent.

User Control

  • You choose when to paste or capture prompt text.
  • You choose when to click Prepare only or Prepare & insert.
  • You choose whether to copy or insert the optimized prompt.
  • You choose when to send the message in Gemini™ or ChatGPT. The extension does not send it for you.
  • You can clear current-session prompt and metric data by unchecking consent or closing the side panel.

Retention

The extension keeps current prompt text, prepared output, token counts, and strategy only in the open side-panel session; it stores no usage history. Token Optimizer processes prompt text in memory only for the time needed to return the preparation response and does not intentionally write it to application logs or a database. Pseudonymous rate-limit records expire shortly after their configured protection window. Hosting infrastructure may retain limited request metadata, such as time, route, status, and network address, under the host's security and retention controls.

Deletion and User Requests

You can clear current-session prompt and metric data by unchecking consent or closing the side panel. Because Token Optimizer does not retain raw or prepared prompt text or usage history, there is no server-side prompt archive or extension history to delete. For help with a privacy or deletion request, use the developer support contact shown on the Chrome Web Store listing. Do not place sensitive information in a public GitHub issue.

Chrome Web Store Limited Use

Token Optimizer's use and transfer of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide or improve the extension's single purpose and security. It is not used for personalized advertising, creditworthiness, lending, or unrelated purposes, and humans do not read prompt text except with the user's specific consent or when required for security or legal compliance.

Children

Token Optimizer is not directed to children under 13. Users should not submit sensitive personal information, secrets, credentials, or private data they do not want processed for prompt optimization.

Changes

This policy may be updated as Token Optimizer changes. The effective date at the top of the page will be updated when material changes are made.

Contact

For general questions, open an issue at github.com/adiarora06/TokenOptimizer/issues. For private privacy questions or deletion requests, use the developer support contact shown on the Chrome Web Store listing and do not include sensitive information in a public issue.
